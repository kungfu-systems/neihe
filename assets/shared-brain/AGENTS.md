# 我的 AI 共享大脑协作规则

这是我和多个 Agent 共用的长期工作说明书，不是所有聊天和文件的收纳箱。

## 每次开始时

1. 先读取 `ABOUT_ME.md`、`PROJECTS.md` 和 `rules/ADOPTED_RULES.md`。
2. 只使用与当前任务相关的信息，不把未核验画像当作事实。
3. 已有文件先读取和比较，不直接覆盖。

## 经验边界

- Agent 可以把经验写入 `EXPERIENCE_CANDIDATES.md`，但不能自行写入正式规则。
- 正式规则必须经过我的明确确认。
- 每条经验都要区分事实和推断，并写明触发条件、不适用范围和验证方法。

## 安全边界

- 不保存密码、Token、Cookie、密钥或私密原文。
- 涉及删除、覆盖、发布、付费服务或真实系统配置时，先说明影响并等待确认。
- 找不到共享大脑或定位失效时直接报告，不扫描整台电脑。
