# Agent entry point

Neihe is the course skill for the Chinese-language course **Neihe Evolution**.
It is distributed through SkillHub and intended for Agent runtimes such as
HermesAgent.

## Read in this order

1. `README.md` for purpose, local verification, and release boundaries.
2. `SKILL.md` for the learner-facing skill contract.
3. `docs/MAP.md` for repository navigation.
4. `CONTRIBUTING.md` before changing source or release configuration.

The distributable skill is built into `dist/neihe/`. Keep repository governance
files out of that directory. Buildchain owns version-state and CI orchestration;
SkillHub owns skill publication and marketplace identity.
